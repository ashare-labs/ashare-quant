# 两股完整会话真实验收（dev18）

三个完整Python脚本在原生RQAlpha账本和撮合上执行，使用AD公开导出的实际原始数据。
比较对象为此前已经封存的真实JQ运行，本轮没有新建平台运行或使用因子额度。
这是2026-10-09、10-12两股的显式事后研究结果，不能推广成全API或历史PIT兼容。

## 固定输入与复验

| 对象 | 固定身份 |
|---|---|
| AD提交 | `2b382e1113ce1e55a145d846c6a29f8555ad25ee` |
| AD wheel SHA256 | `9e175a643ffe483c0f576d22490b0bf1c9360b961f0248addccba8382af77450` |
| AD导出 SHA256 | `393a44c5d9b2fd70fa156c53f9175350d68199575181ccc64a45b40594b86381` |
| AQ投影 SHA256 | `3baad1cca4695ab896ea7f16556a3aeeb198ec2ff85809bebff6898e37aee0b5` |
| 继承状态/行动输入 SHA256 | `8e9320af8ac8b5c51dc5ca67112199c8969fe3a34a71d1a20497d24a9d2c52b2` |

`session_input.py`校验AD交付141个文件，再将AD明确的`closing_auction_candidate`
投影为来源绑定的AQ收盘研究角色。960条执行、480条预热、开盘单值、收盘估值和日汇总
全部保留原值及未知源时钟；状态、行动、覆盖、日历、state_replay和原source_refs逐项不变。
四条执行日14:59的0量/0额、两条预热零量均保留。没有删除、填价或按JQ修量。

在依赖已安装的AQ源码目录中，用新的输出目录运行：

```sh
python -m examples.jq_minute_comparison.session_input \
  --ad-package AD_DELIVERY --inherited-input OLD_INPUT --output NEW_INPUT
python -m examples.jq_minute_comparison.session_compare \
  --input NEW_INPUT --ad-export AD_DELIVERY/session-source.json \
  --inherited-input OLD_INPUT --jq ORIGINAL_JQ_CAPTURE \
  --gap-reference GAP_JQ_CAPTURE --output NEW_RUN_DIRECTORY
```

可另用`--existing RUN_DIRECTORY`只读重验。发布交接包附原AD交付、三个真实JQ捕获、
源码/wheel、全部输入输出及复验脚本，离线运行不依赖主工作树。版本相同的AD旧wheel
不是本次交付，必须核对上述SHA。AQ运行仍保留原固定AD运行依赖，数据导出在独立环境完成。

## 实际结果

两份原策略的观察版仅把原AQ专属断言改成记录，保留真实业务AST、信号和下单决策。
容量脚本`gap_ported.py`与上传聚宽的完整165行脚本相比，仅在历史查询明确增加`fq=None`。

| 脚本 | 订单/成交 | 10-09盘后权益 | 最终权益 | 观察记录/账户快照 |
|---|---:|---:|---:|---:|
| shared_cash_t1 | 5 / 5 | 98,638.2694 | 99,793.5454 | 86 / 47 |
| visible_momentum | 2 / 2 | 99,024.0708 | 100,184.042 | 54 / 37 |
| gap_ported | 5 / 9 | 9,994,169.26696 | 10,000,595.82696 | 165 / 48 |

每项权益与真实JQ参考一致（核算容差1e-7元），旧190元和136元收盘差已由AD真实15:00
估值记录消除。所有信号历史、委托计划、订单返回、成交时间/数量/价格/费用、可用现金、
冻结现金、持仓及T+1数量逐项核对。每份脚本每日240个handle_data回调；305条观察记录
的序号和时钟全比，不能用只比较最终收益代替生命周期验收。

容量脚本保持同刻A两单各9400股、B10700股；午间限价9400+10+89股，末段9400+86+127股。
15:30仍挂单且冻结874,050.843526元，下一交易日09:00回调前释放；最终A37912股、B10700股，
现金9,508,475.786960元。精确撤单时刻仍只有区间证据。

发现并修复终端对象差异：两份原策略在JQ的`on_strategy_end`中，当日订单/成交集合为空，
旧AQ仍返回末日记录。dev18在此查询边界返回空集合，保留原生结果和15:30集合。
真实末日挂单的终端表现尚未验证；沿用已声明的原生保留模型。

`session_boundaries.py`另用同一真实输入检验09:30预热与日量可见性，以及四条零量时刻
新市价、限价及旧挂单都不成交；这是AQ政策边界测试，未冒称新增JQ实测。

## 保留的差异和范围

完整逐字段比较共匹配8197个叶字段。所有差异在`comparison.json`逐项保存：

- TDX/JQ成交量有27次观察差异（23次分钟观察对应12条不同原行，另4个日量），不改源数。
  例如600000在10-09日量94,795,800与94,795,849；15:00量1,272,500与1,272,543。
  在本参与率下整手/整数股容量结果相同，不能因此唯一识别平台精确分母。
- AD没有认证历史交易所涨跌停价，AQ明确报不可用。166次字段差异保留，不能借JQ日志
  补入运行价格板。既有研究执行包络仍是模型约束。
- AQ额外Trade.at/side/commission/tax有188次观察，JQ对应属性不可用；LimitOrderStyle
  公开price与JQ私有`_limit_price`有6次表示差异。两端平台身份有2处预期差异。
- 原生浮点冻结余额最终可能有约`-3.5e-10`元尾差，保留原值并在容差内核算。

仍未实证：多旧挂单同刻容量分享、相等触价、只有high/low穿价、卖单对称、非零滑点、
09:30代理成交、零量新单在JQ的处理、11:30/15:00内部撮合阶段、精确日单撤销时刻。
AD开盘记录的`matching_allowed=false`保持原样：它是单值代理，不是提前可撮合的完整BAR；
本次真实三脚本仅观察开盘，没有在09:30下单。AQ显式开盘成交模型的工程测试不能替代该实证。

支持的首批API见[主接口清单](../../docs/python-minute.md)和[会话政策](session-policies.md)。
未知API显式失败；复权、5m、因子/财务、动态股票池、多账户、tick、实盘及严格交易所竞价
模型均未增加。量与开盘/收盘角色是non-PIT研究输入；源历史可用时间、完整状态和公司行动
未认证。`result.jq_comparison`保持`NOT_PERFORMED`，真实比较结论单独绑定于报告和固定输入。
