# 历史组合与数据发布

七算法注册、目录、预检和执行服务已从产品删除，`/api/v1/portfolio` 不再提供接口。新研究使用自定义 Python 日频/分钟工作台，不再通过算法 ID 选择预置代码。

历史组合任务通过 `/api/v1/history/jobs?family=portfolio` 读取。原策略定义、请求、输入、摘要、交易、账户和权益记录保留，结果从已封存产物返回；不加载旧算法重算，也不提供重新提交或恢复旧固定算法的兼容平台。已保存的用户策略在 `/api/v1/history/strategies` 可读。

正式数据查询、参考资料覆盖、公司行动、财务查询和发布接口保持在 `/api/v1/product`。发布使用独立的 `market.datasets.Datasets` 保存数据描述与输入，不再实例化策略注册器或组合任务服务。原始数据、发布文件和目录身份不变。

`covered_research` 保留实际来源、逐日状态、价限和公司行动覆盖要求；`price_only_no_limits` 仍为显式的数据诊断模式，不会自动替代正式研究。数据发布返回的描述保留原协议字段；这些描述不直接授予策略执行权限。自定义 Python 从所选正式 release 冻结数据并独立完成准入。

共享的日线账户、公司行动、分钟撮合、T+1、费用及恢复检查点代码仍保留。已登记账户的独立运行时依赖 `portfolio.signals` 等组件，此次不迁移或删除这些账户代码；它们不再有产品侧算法注册与新建回测入口。当前正式服务是否切换由前端联调后的单独发布决定。
