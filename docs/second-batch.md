# B40–B45 有界原题研究入口

入口执行摘要固定的原始可信策略源码，以薄接口调用 RQAlpha 原生订单、成交、账户与持仓。运行时只读取策略和 AD 数据绑定；JQ 账户、订单、成交参考仅进入离线对照。该入口不扩大通用任务服务的股票、日期或 API 范围，也不声称全市场等价。

使用 `python -m ashare_quant.second_batch.runner --request REQUEST --output NEW_DIRECTORY`，要求 `-I -S -B` 新进程，显式指定策略摘要和 AD reader 源码摘要。每个账户一个进程，拒绝覆盖输出。输出包括原脚本事件、原生事件、AD 请求响应、配置、源码摘要、订单、成交和完整封印。原始行情与研究运行不进入公开包。

## 明确选择模型

`native-before` 保留首次接通入口时的原生数量及全日容量政策；`fixed` 保留第一阶段数量、分钟容量修复及当时的估值缺口；`integrated` 在其上加入以下有证据的适配。未知 policy 直接拒绝。

- 即时提交采用显式的事后全日容量研究模型。后续挂单读取当分钟实际量，按股取整，不再次按委托整手向下取整。挂单买入限价严格高于已观测 Bar low 时，使用原委托限价成交。这对应[聚宽公开 API 文档](https://cdn.joinquant.com/help/img/JoinQuantAPI.pdf)“回测环境下的撮合机制”对即时成交和 Bar 成交的区别；该价格是模拟委托成交价，不冒充行情观测价。仍由原生 matcher 创建成交。
- 股票现货多头、100 股买入整手、T+1；卖单准入上限来自原生 closable，保留原始请求和实际准入量。全仓零股卖出不先降至整手。
- `integrated` 在原生 Account 子类中更改活跃买入限价单的冻结：原始委托数量×限价，减实际已成交金额与累计费用；全成或撤单释放余额。没有第二份现金或持仓账本；原生 apply_trade 处理现金、成本与持仓。支持多次部分成交、并存订单、重复事件校验和终态释放。仅支持从空持仓新建的股票账户，不支持检查点恢复或融资。
- 预计费用继续参与原生购买力检查。因此 B42 最低佣金分支保留资金不足拒单，不能复制 JQ 的 -3 元可用现金。
- 当前点、分钟和事后独立点保持独立角色。补充 TDX 点仅用于精确标签的缺失持仓估值，不能供策略或撮合读取；AD 校验原始记录与单位。其日期来自请求、分钟来自协议序号，响应未回显证券和日期，不提升为历史 PIT。若仍缺点价则显式记录 gap，对应对照字段不算通过。
- B45 的登记、除息、现金支付、转增到账及无限售新增股可交易日期由 2016-025 实施公告独立确认。当前只接纳到账、可交易与除息同日的模型，不同日期明确拒绝。原生 StockPosition 处理转增与现金。09:00 生效仍是研究时钟假设。
- B45 盘前参考价由 AD 读取新浪独立编码的 ex-session prevclose；现金与转增公式仅做一源价格单位以内的冲突检查，不生成或舍入价格。缺标记即拒绝，不改用当日 OHLC。AQ 仅通过原生 update_last_price 更新估值，并保护现金、持仓状态及未复权前收。
- 既有 20% 预扣税是 JQ 模拟规则。实施公告记载实际税款按持有期在转让时补扣，本研究不把模拟现金时序作为真实税务处理。

会话与前日来自固定 day_start 数据；末日不构造次日交易日或强制清仓。订单均价保留原生完整精度，不从单个 JQ 三位小数样本推断通用舍入法。结束阶段的订单/成交集合、T+1 状态及 1ms 时钟差异保留在原始对照。

## 验证与集成

`tests/second_batch` 使用不同于题库的数字验证可卖量、共享容量、两次原生成交、费用累计、并存冻结、撤单幂等、全成释放和含费拒单。真实原题必须另外提供固定策略和 AD 绑定，合成测试不能替代实际触发。

该工作保留已核验的 B26 源参考价模型与 B12 可观察开盘/撤单模型。B26 的固定 AD wheel 独立摘要锁继续有效；B12 原生成交时刻仍为 09:30、首个策略可见时刻为 09:31，不宣称独立证明 09:25 撮合。第二批 AD 读取绑定使用集成树的逐文件摘要，数据修复归 AD。

README 五章、公开依赖版本、锁文件及既有整理成果保持。所有结果仅支持声明的样本与输入，不包含发布、部署或因子 F2 扩展。
