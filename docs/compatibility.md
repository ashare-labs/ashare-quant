## 四项实质差异

| 题目与目标 | 已证差异和保留的未知 |
| --- | --- |
| B25：raw/pre/post 复权与基准日 | 因子、价格和量处理不同，AD 产品保留原价量额。完整行动链、JQ 归一及精度未认证；2007 日期已由修订公告解决，特殊股改仍不能套普通分红公式，1991 事件链不完整。 |
| B26：公司行动净现金、成本和盘前估值 | 净红利、成本、数量和期末权益相符；一个盘前估值输入差异影响四个字段。当时可读的参考价、精度及处理顺序未证，不能硬编码参考值或盘后倒填。 |
| C02：字段覆盖与数值 | 原价前收及恒等系数已标准化；量额和派生均价有来源精度差。high_limit、low_limit、open_interest、vwap 仍 unsupported；派生 avg 不是源生值，原价前收不是除权参考价。 |
| C03：历史最早非空与覆盖 | 固定窗口共有行一致，独立来源有更多早期历史；停牌记录解释已有缺日。覆盖差保留，完整官方停牌链、PIT、绝对最早行情与完整证券信息产品未认证。 |

实质差异可能来自来源约定、字段能力、覆盖或模型，不一律意味着 AQ 或 AD 缺陷。

## 六项证据不足

| 题目与目标 | 缺证据及影响 |
| --- | --- |
| B12：竞价撮合 | 行情不能证明用户订单参与独立竞价撮合；缺当前机制证据，开盘价相同不足以证明内部撮合一致。 |
| B14：费用分项 | 总费用相符，原生佣金/税等分项未提供，UserTrade 费用字段未探测；公式拆总额不是分项观测。 |
| B17：独立过户费 | 缺构造器独立过户费参数及原生字段证据；原脚本未传该参数，不能推断接口拒绝或真实费用为零。 |
| B27：分钟行情 | 缺固定三根分钟的真实 OHLC、逐股量、独立金额与精度；三秒分组档案无法提供组内 OHLC 或独立金额。 |
| C01：历史证券全集 | 缺同日完整独立集合及历史上市、退市、类型、名称与覆盖证据；当前名单或指数子集不能替代。 |
| C05：时效与修订 | 两个归档提交值相同，不证明两个上游采集或值修订；发布时点、revision 与完整交易日覆盖未认证。 |

## 服务范围

持久任务服务为 `m2-jobs.v6`，范围见[研究任务](research.md)。`execution_six` 与 `round_one` 是固定研究驱动，需要各自固定的 reader 和数据绑定，不是通用 SDK。源码中的摘要、研究参数及历史输入定位信息不提供对应行情或私人运行材料。

当前没有全聚宽兼容、严格 PIT、持续实时 paper 或真实券商完成声明。quant-web 独立维护，后端整理不构成新的前后端联合验收。
