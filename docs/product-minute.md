# 产品 API 中的已注册分钟查询

常规产品 API 将分钟读取委托给已安装且内容绑定的 AD `LocalMinuteProduct`。该接口直接复用既有部署/产品配置（包含已显式初始化的控制状态与配对 AD 运行时），不接受请求中的 owner 覆盖、文件系统路径、修复选项或成交许可标志，也不会创建回测任务或数据发布。

`GET /api/v1/product/minute/sources` 返回已配置的来源 ID、配置默认来源（未指定时为 `tdx`）、精确的资产与证据绑定、已注册覆盖范围及使用限制。来源发现不会扫描底层文件库；格式错误的注册项按来源单独报告。高频读取时请显式指定返回的来源 ID：

```json
{
  "security": "600000.XSHG",
  "start": "2026-06-03T09:40:00+08:00",
  "end": "2026-06-03T09:42:00+08:00",
  "source": "neigezhu"
}
```

将该请求体发送至 `POST /api/v1/product/minute/prices`。省略 `source` 或传入 `auto` 会选择当前配置的默认来源（对市场发布可为 `canonical`），而非隐式降级回退。时间戳必须带时区偏移且精确到整分钟。查询区间为闭区间，限定单只证券并返回完整请求区间，不设固定天数或行数上限。北交所保留原生标识 `BJ.920000`，不做猜测映射。既有日频 `/prices` 端点及其 `auto` 来源策略保持不变。

响应原样保留 AD 的 `source`、`binding`、`rows` 与 `report`。异常行、零成交量行、来源标签、特殊数值编码、审计证据及行级拒绝裁定均不过滤；空行或未知覆盖不会升级为完整交易日。读取器恒为 `false` 的成交标志仅表示读取器不签发成交许可，而非禁止一切研究用途。既有受控研究调用方仍需具备经审核的证据，且不得覆盖来源绑定的行级拒绝裁定；详见[分钟来源使用说明](minute-source-use.md)。

配置身份包含分钟注册表与解析后的资产路径。API 进程保留启动时的配置快照。一旦发生语义级部署配置修改、解析后的资产路径变化或部署文件不可读，服务即锁定 `PRODUCT_CONFIGURATION_CHANGED`（HTTP 409）并要求重启 API。分钟读取在打开底层读取器前、针对读取器加载的原始配置副本以及读取完成后均会校验配置一致性。AD 可在不改变部署快照的前提下从已绑定的市场发布中新增或替换运行时读取器资产，但变更后的绑定不得在旧配置身份下返回。此时 `/config` 会报告 `configured=false`、需重启错误与启动配置身份，而不会声称变更后的环境已就绪。仅恢复原文件不会解除锁定状态；重启后，新解析的配置与分钟绑定会生成新的配置身份（即便内容相同但路径变化也会更新身份）。仅 JSON 空白字符或键顺序变化不会改变配置身份；固定配置内的内容/哈希校验失败仍归属具体来源错误，不触发部署变更锁定。

既有产品中间件继续执行本机来源检查与 `Cache-Control: no-store`，并拒绝查询参数与未识别的 JSON 字段。API 沿用常规 AD 运行时与依赖校验（含 wheel 与源码哈希绑定）。

当前 Web 产品来源选择器面向日频发布接口，其 Store 别名/数据集浏览也不是本原生分钟库注册表。未来若提供轻量分钟查询面板，可复用常规产品客户端与来源校验，拉取 `/minute/sources` 并展示 `/minute/prices`（含行级质量信息），但不得将原生分钟结果混入日频发布或静默当作回测成交输入。

读取前后的配置校验并非原子文件系统快照：若符号链接瞬时切换至字节完全相同的内容又切回，可能保留旧配置身份并报告临时解析路径；而内容不同仍会触发既有哈希校验失败。受控集成应使用固定的非符号链接来源路径，并在经授权的资产迁移后重启服务；运行时动态切换符号链接不在本配置契约支持范围内。
