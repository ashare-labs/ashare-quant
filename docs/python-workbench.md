# Python 策略工作台

网页 `#/workbench` 是自定义 Python 分钟研究入口。导入或编写 `.py`，配置股票池、日期、资金和 JSON 参数，确认可信代码与回溯模型后选择“准备数据并回测”。系统从当前正式发布冻结来源、参考资料和策略；不要求手动发布数据。`#/portfolio` 保留七种日频算法示例，固定窗口的受限日频 Python 仍在原任务入口。

策略定义 `initialize(context)`；可选 `before_trading_start`、`handle_data`、`after_trading_end` 和 `run_daily`。`context.parameters` 返回参数副本，`context.securities` 是本次固定股票池；数据查询仅访问已准备股票及已可见分钟。原价历史查询需显式 `fq=None`。已有 jqdata 子集提供 history、attribute_history、get_price、get_bars、get_current_data、委托/撤单、record 和 log。没有全市场动态扫描、财务查询或任意频率能力。

本机任务入口最多 8 股、23 个交易日、20,000 根股票分钟线且不跨越 31 个自然日；输入文件上限 64 MiB、总任务产物门禁 512 MiB，沿用共享队列 CPU、内存、输出和执行时限。边界按本轮真实样本的序列化大小设定，不代表底层引擎容量上限。

数据采用 `source-labelled-corporate-date-model.v1`：按原标签构造已收盘模型，日状态于 09:00 回放，原价、每分钟量限制、下一分钟开盘撮合、T+1；涨跌停使用日线前收 5%/10% 研究模型。公司行动是冻结来源观测和日期到账模型，不宣称完整历史 PIT。初始与结束持仓均须为空，策略须自行在结束前平仓；不会自动平仓掩盖策略逻辑。确认价格无效的分钟经 AD 标准读取转为明确缺失，准备器沿用 `ad-minute-research.v1/unavailable_minutes` 保留时刻、原因和原件定位；历史接口在原时间位置返回 NaN，不成交、不产生新估值。单独 conflict 保留原值和 deny。未声明的源缺口、部分量额缺失、未知状态或不支持的公司行动仍返回具体错误，不补行情或转成价格诊断。09:30 等模型时段外标签在 preparation 报告列明，原件不改。

HTTP `/api/v1/python/catalogue` 返回示例和提交环境身份；`POST /jobs` 接受源码、参数、固定选择、环境身份、幂等键和两项明确确认。任务与日频/组合共享原有队列、租约、资源监控、取消和进程组终止机制。一个受控进程准备输入后直接调用现有分钟 `run_native`；没有第二套撮合引擎或嵌套失控进程。只对可信本地代码开放，这些限制不等于恶意代码沙箱。

浏览器先保存原请求再提交。重复点击/网络重试用同一键；环境变化时拒绝将未知结果自动转投另一个环境。返回或刷新只读取任务。取消停止进程、不发布结果；任意 Python 内存不支持断点恢复，中断任务只能由用户明确新建一次。旧源码版本的控制库继续使用原固定运行时，不原位绕过数据库兼容门禁。

任务目录保留源码、提交配置、发布身份、输入、准备报告、原生事件与结果，来源和运行依赖均冻结。结果显示区间收益、期末权益、日末最大回撤、成交、委托原因及日志；不从两日样本推算年化、夏普或盈利承诺。既有模拟账户与行情原件不写入。
